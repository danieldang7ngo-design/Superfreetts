## Shape

```
Anki UI (gui.py + component_*.py)
  → SuperFreeTTS (superfreetts.py) — facade, wires every manager below
      ├ ConfigStore (config_store.py)      Anki config dict: presets, workflows, mapping rules
      ├ BatchOrchestrator (batch_orchestrator.py)
      │     prepare text → dedup (text+voice+format) → MultiEngineExecutor
      │     → audio_file_store hit/miss → service.get_tts_audio_batch() → write [sound:...]
      ├ AudioGenerator (audio_generator.py)  single note: text → voice → file → tag
      ├ RealtimeManager (realtime_manager.py)  {{tts superfreetts_preset=X}} during review
      └ EditorManager (editor_manager.py)     editor buttons, mapping rules
ServiceManager (servicemanager.py) lazy-instantiates engines; ServiceBase (service.py) is the
ABC — every `services/service_*.py` implements voice_list() / get_tts_audio() / get_tts_audio_batch().
Remote: EdgeTTS, GoogleTranslate, Cambridge, Duden, DWDS, Oxford, SpanishDict, Youdao.
Local: Piper, Kokoro, MMS/Sherpa, Supertonic, eSpeakNG, macOS `say`, Windows SAPI
(persistent subprocess pools + JSON stdin/stdout IPC in `services/process_pool.py`).
Disk cache: audio_file_store.py — content-addressed SHA-224 filenames.

## Invariants — never break

- EdgeTTS worker cap = **3**, immutable (test-enforced)
- Source `.py` files must stay **CRLF**
- No `psutil`, no compiled/C-extension deps vendored
- All Anki/aqt API calls go through `anki_utils.py` (keeps the test suite Anki-free)
- Batch resume semantics live in `batch_executor.CheckpointManager` / `BatchCheckpoint`
